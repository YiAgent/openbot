## Decisions made
- **手写 YAML 单字段扫描**而非 `pyyaml`/`ruamel.yaml` —— Why: 引入解析器把 langsmith.py 的 import 链拉长（被 `scripts/validate_langsmith_run.py --help` 在 CI placeholder job 也间接 import），手写 30 行 `for line in text.splitlines(): if line.strip().startswith("public:"): ...` 已够；manifest schema 在 E2-T01 落 real 文件后如果嵌套，再升级到真解析器。Follow-up: 一旦 manifest 出现 nested public 字段（PRD §7.2 目前是顶级），换 yaml。
- **缺 manifest / 缺 `public` 字段 → fail-safe 到 `internal`** —— Why: PRD §13.2 末段「公开 release artifact 不允许贴 raw internal sample 内容」是 hard SOC；错把 internal 当 public 会泄密，反过来不会。Fail-safe 朝 internal 偏。Follow-up: 单测 `test_missing_manifest_fails_safe_to_internal` 钉住这一行为。
- **`yes`/`1` 也算 `True`** —— Why: YAML 1.1/1.2 都把 `yes/no/true/false/1/0/on/off` 当 bool 别名；放宽解析避免「手写 manifest `public: yes` 时静默错误归类」。Follow-up: `on`/`off` 不在白名单（用了就 fail-safe 到 internal）；如果需要再加。
- **`init_client_for_dataset` 是 sugar，不替换 `init_client(*, public=...)`** —— Why: 有些 entry point（如 manual one-off run）调用者可能没 dataset_version 在手（比如 dry-run）。保持低层 API + 高层 sugar 是 idiomatic。Follow-up: none。
- **测试不真创建 `langsmith.Client`** —— Why: 不需要 network；通过 `patch.object(ls, "init_client", ...)` 或 `monkeypatch.setitem(sys.modules, "langsmith", FakeLS)` 把客户端构造层挡住。E1-T04 unblock 时再加 live test。Follow-up: none。
