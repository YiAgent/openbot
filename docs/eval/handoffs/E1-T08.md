## Decisions made

- **Synthetic 5-sample dataset, NOT real Martian** — Why: the upstream Martian benchmark commit-lock is E2-T01's job; pulling a real upstream benchmark mid-stack would expand scope. 5 hand-authored samples covering diverse defect classes is enough to prove the pipeline. Follow-up: keep this smoke fixture for cheap checks, and add the real Martian dataset as the comparable public baseline in E2-T01.
- **Heuristic judge for the smoke** — Why: PRD §10.3 LLM judge would burn tokens for every (golden, candidate) pair (5 samples × N candidates each = ~10-20 judge calls). For pipeline validation, deterministic file+line+keyword overlap is sufficient and CI-cheap. The pure scorer `compute_review_overlap` (E1-T07) accepts any `judge_fn` so swapping is trivial. Follow-up: next baseline run uses `evals.common.judges.Judge` and writes a new `baseline-log.md` row with the LLM-judge numbers.
- **`public: false` on `martian_smoke_v1`** — Why: even though the data is synthetic (no PII), keeping smoke runs in the internal LangSmith project until v0.1 ships avoids accidentally publishing "0.833 mean F1" as if it's a real Martian baseline. PRD §13.2 fail-safe. Follow-up: real Martian dataset (E2-T01) gets `public: true` so it lands in the public project for community comparability.
- **`logs/` is gitignored** — Inspect AI writes `.eval` logs to `logs/`; CLAUDE.md "Forbidden" lists `evals/logs/` but this is `logs/` at repo root (Inspect's default). Verify it matches gitignore; if not, add. **TODO before commit.**
