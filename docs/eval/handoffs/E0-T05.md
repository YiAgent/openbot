## Decisions made
- 测试放 `tests/eval/`、**不**放 `evals/` —— Why: PRD §8.3 + CLAUDE.md "Forbidden" 都说 LLM-behavior / prompt-quality 断言才进 `evals/`；config 常量是 deterministic Python 数据，归 `tests/`。又：Makefile + pre-push hook 都 `--ignore=evals`，放进 `evals/` 反而不会跑。Follow-up: 后续 E1-T02 LangSmith client 单测同理放 `tests/eval/`。
- 用 `MappingProxyType` 包 dict 而不是 `frozenset/namedtuple` —— Why: PRD §11.1 YAML 是 mapping 语义（按 suite/mode 索引），keys 数量可能扩展（如未来加 `libro_reproducer`）；`MappingProxyType` 在 import-time 锁定写入但保持 dict-like 接口，下游不改写代码。Follow-up: E1-T07 cost guardrail 真接通时直接 `config.PER_SAMPLE_USD[suite_name]` 读，超过 1.2× 抛 budget_stop。
- 测试**显式硬编码** PRD §11.1 的数值字面量（不引用 `config.PER_SAMPLE_USD` 自身做 round-trip）—— Why: 这是 governance test——常量被悄悄改时必须能 fail。如果测试只是 `assert config.PER_SAMPLE_USD == config.PER_SAMPLE_USD`，改值时仍 green。Follow-up: PRD §11.1 改值时同步改 `test_config.py` + 写 `baseline-log.md` 一行（E0-T03 已建模板）。
- `# 1.2x` 而不是 `# 1.2×` 注释 —— Why: ruff RUF003 把 `×` 标为 ambiguous Unicode（与 `x` 视觉混淆）；统一改 ASCII 避免 lint 噪音。Follow-up: 项目内其它注释里如需「×」，可在 `pyproject.toml` 加 ruff allowed-confusables，但 E0 阶段不值得。
- `from collections.abc import Mapping` 而不是 `from typing import Mapping` —— Why: ruff UP035 强制 PEP 585 风格（typing.Mapping deprecated in 3.9+）。本仓 Python 3.11，照规则即可。Follow-up: none。
