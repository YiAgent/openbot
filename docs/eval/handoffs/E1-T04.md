## Unblock checklist

When you've got a LANGSMITH_API_KEY:

1. `doppler secrets set LANGSMITH_API_KEY=...` (or export locally).
2. 实现 `export_artifact` 主体：
   - `client = client or langsmith.Client(api_key=os.environ["LANGSMITH_API_KEY"])`
   - 调 LangSmith artifact / attachment SDK（具体 fn 名见 langsmith ≥ 0.4 文档；可能是 `client.create_attachment(run_id, ...)` 或 `client.upload_artifact(...)`）。
   - 返回 ref URL/id。
3. 写 `tests/eval/test_artifacts_live.py`：
   ```python
   import pytest, os
   pytestmark = pytest.mark.skipif(
       not os.environ.get("LANGSMITH_API_KEY"),
       reason="needs live LangSmith credentials",
   )

   def test_export_round_trip(monkeypatch):
       ref = export_artifact("smoke-1", "log", b"hello world")
       assert ref.startswith("http")  # or whatever LangSmith returns
   ```
4. 在新 commit 上把 `export_artifact` 调用从 NotImplementedError 改为真实现，handoff status `❌ blocked` → `✅ done`，AC 勾上。
